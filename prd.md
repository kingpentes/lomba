Functional Requirements (FR)4.1 Real-Time Telemetry & Alert StateFR-01 (State Machine Display): Sistem harus menampilkan banner status status sistem dengan 3 level visual yang jelas:NORMAL / SAFE (Hijau): Kondisi tenang, akselerasi gravitasi stabil (~1g), tidak ada pergeseran.OPERATIONAL NOISE (Kuning): Getaran terdeteksi (misal simulasi peledakan/kendaraan), frekuensi tinggi, namun orientasi kemiringan lereng tidak berubah permanen.CRITICAL HAZARD (Merah berkedip + Audio Alert opsional): Perubahan sudut lereng permanen dan akselerasi abnormal terkonfirmasi oleh model AI.FR-02 (Live Sensor Cards):Akselerasi 3-sumbu ($Acc_X, Acc_Y, Acc_Z$) dalam satuan $m/s^2$ atau $g$.Sudut kemiringan real-time (Pitch dan Roll) dihitung dengan rumus:$$\theta_{\text{pitch}} = \arctan\left(\frac{A_y}{\sqrt{A_x^2 + A_z^2}}\right) \times \frac{180}{\pi}$$Estimasi getaran puncak (Peak Acceleration / PPV proxy) dan frekuensi dominan.4.2 Telemetry VisualizationFR-03 (Rolling Multi-Axis Chart):Menampilkan visualisasi garis (line chart) untuk ketiga sumbu akselerasi ($X, Y, Z$) secara bersamaan.Mempertahankan jendela data bergerak (sliding window) sebanyak 30 hingga 50 titik terakhir dengan animasi render mulus (smooth live stream).4.3 Visual Verification & Incident LogFR-04 (Snapshot Capture on Alert):Ketika status sistem berubah menjadi CRITICAL HAZARD, backend harus memicu pengambilan 1 frame gambar dari webcam lokal.Gambar disimpan ke folder lokal dengan format nama alert_<timestamp>.jpg.FR-05 (Incident Log Table):Tabel riwayat insiden memuat: Timestamp, Trigger Class, Confidence Score (%), Tilt Delta (°), dan Evidence Snapshot.Mengklik baris insiden membuka modal/tampilan gambar bukti kamera.FR-06 (Data Export):Tersedia tombol unduh "Export Incident Log" yang menghasilkan file incident_report_<date>.csv.5. Non-Functional Requirements (NFR)Performance: Latensi pengiriman data dari ingestion script hingga tampil di grafik browser maksimal 150 ms.Reliability: Jika koneksi serial/WebSocket terputus, UI harus menampilkan badge status DISCONNECTED dan mencoba melakukan auto-reconnect setiap 3 detik.UI/UX: Desain bernuansa industrial (dark mode), tipografi monospace untuk angka metrik, dan kontras warna tajam (latar gelap #0f172a, hijau #22c55e, kuning #eab308, merah #ef4444).Portability: Dapat dijalankan secara lokal pada satu laptop tanpa konfigurasi layanan eksternal berbayar.6.
